Writing a grant report from program data

Grant renewals and state program reports ask for the same three sections every year: the need, the outcomes, and the next steps. A program coordinator usually writes them by hand from a table of program numbers. Here, the coordinator gives the AI the program's data table and the program lead's notes and asks for those three sections. The AI is told to use only numbers from the table, to name the table row behind every sentence, and to list anything in the notes that the table does not back up.

Choose a program to see its data and the report that comes back. Then click any sentence in the report to see the row it came from. The full table opens with that row highlighted.

Before you use it

    
The coordinator checks every number against the source data and the funder's required wording, and the program lead signs off before the report is submitted. Clicking each sentence shows its source row and any calculation, which is where that check starts.
